# Neumorphic Login & Sign-Up UI

A clean and modern **Login & Sign-Up interface** built with pure HTML, CSS, and JavaScript. It features a soft neumorphic (clay) design, smooth 3D card-flip animations, and an animated blue light around selected input boxes.

---

## ✨ Features

- **Soft Neumorphic Look**: Clean, extruded clay style with realistic soft shadows.
- **3D Card Flip**: Click **Sign Up** to flip the card to the left, and click **Log In** to flip back.
- **Looping Blue Light**: A glowing thin blue light moves around any input box you click on.
- **Show / Hide Password**: Easily toggle password visibility with the eye icon.
- **Form Validation**: Helpful error messages and shake animations if fields are empty.
- **3 Color Themes**: Switch between **Clay** (default), **Soft Blue**, and **Dark Clay** with one click.
- **Responsive**: Works smoothly on mobile phones, tablets, and computers.
- **No Installations Needed**: Pure vanilla code with zero external libraries or frameworks.

---

## 🚀 How to Run

### Method 1: Just Double-Click
Simply double-click **`index.html`** in your file explorer to open it directly in your browser.

### Method 2: Run with PowerShell (Windows)
1. Open PowerShell inside the project folder.
2. Run:
   ```powershell
   .\server.ps1
   ```
3. Open your browser and go to: `http://localhost:5000/`

---

## 📁 Project Files

- **`index.html`** – The HTML structure for both Login and Signup cards.
- **`style.css`** – Neumorphic styling, 3D flip animation, and looping light effect.
- **`app.js`** – Card flip actions, password toggles, and form validation.
- **`assets/`** – Lock icon image.
