# Login UI
A neumorphic Login and Signup interface built with HTML, CSS, and JavaScript.
- **3D Card Flip**: Clicking "Sign Up" flips the card left to show signup slots, and "Log In" flips back.
- **Looping Blue Light**: Selecting an input box displays a thin blue light moving around the border in a loop.
- **Theme Switcher**: Supports Clay, Soft Blue, and Dark Clay surface presets.
- **How to Run**: Open `index.html` in any browser or run `.\server.ps1`.
